## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Vivek003-coder/Portfolio_V2.git
```

Navigate to project

```bash
cd Portfolio_V2/frontend
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build for production

```bash
npm run build
```
